# lelab
A web-based LeRobot workbench for robot calibration, teleoperation, dataset recording, training, and policy inference.

Research progress: [milestone index](docs/RESEARCH_PROGRESS.md).

The published research milestones document an offline SmolVLA bimanual
training pilot and a later gated run that stopped early under pre-registered
symmetric gripper monitoring. They do not establish simulation task success or
physical robot safety. Model weights, datasets and private runtime configuration
are not included.
