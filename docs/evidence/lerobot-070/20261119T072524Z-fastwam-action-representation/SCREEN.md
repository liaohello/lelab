# A/B 筛选判据（先写定，再跑）

本文件写于 B 组训练**尚未完成**、任何 B 预测都还不存在的时候。判据不因结果调整。

## 对照结构

| 组 | 权重 | processor | 归一化统计 |
| --- | --- | --- | --- |
| `step0-a` | base（无 adapter） | A 的（绝对） | 绝对 |
| `a` | base + adapter A | A 的（绝对） | 绝对 |
| `step0-b` | base（无 adapter） | B 的（相对） | 相对 |
| `b` | base + adapter B | B 的（相对） | 相对 |

四个进程都从**同一 base、同一 seed(1003)、同一数据顺序、同一相机布局、同一优化器预设、
同一更新数(100)、同一推理噪声(seed 2026)** 出发；`step0-*` 目录是把对应检查点的 adapter 两个文件
删掉后的副本，因此 processor 与归一化与各自训练时完全一致。

## 主判据（B 必须同时满足）

1. **首步**：`b` 的左臂关节首步 MAE **低于** `a`；
2. **活跃关节整段**：`b` 的 0–31 步左臂关节 MAE **低于** `a`；
3. **动态段**：`b` 在关节动态窗（GT 位移 ≥5°）上的左臂关节 MAE **低于** `a`。

## 护栏（退化不得超过）

4. **动态夹爪**：`b` 在夹爪动态窗（GT 位移 ≥5 百分点）上的左夹爪 MAE
   **不超过 `a` 的 1.10 倍**；
5. **静态侧**：`b` 的右臂关节（近静止）MAE **不超过 `a` 的 1.5 倍**；
6. **不是靠"贴着当前姿态"刷分**：`b` 的活跃关节整段 MAE 必须**低于它自己的 `step0-b`**，
   否则说明相对表示只是把输出压成了常量。

## 同时报告（不作判据）

- 各组相对 **`state_copy`（保持当前姿态）** 的差距 —— 这是真正的控制门槛，
  上一轮 L5 在这一项上差 4.6 倍；
- 首步 / 0–3 / 16–31 / 整段四段；
- 左夹爪与右夹爪分列（百分点），左臂与右臂关节分列（度）。
