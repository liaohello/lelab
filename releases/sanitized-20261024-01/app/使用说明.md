# LeLab 使用说明

本文档说明如何在当前项目目录中启动、停止和重新启动 LeLab。

## 使用前准备

1. 将机械臂控制板连接到电脑，并接通机械臂电源。
2. 连接摄像头。
3. 打开 PowerShell。
4. 进入项目目录：

```powershell
cd C:\Users\Administrator\Desktop\embodied_intelligence_proj\lelab
```

## 开始运行

在项目目录中执行：

```powershell
.\.venv\Scripts\lelab.exe --no-open
```

看到服务器启动成功后，在浏览器中打开：

```text
http://127.0.0.1:8000
```

`--no-open` 表示启动服务时不自动打开浏览器。

## 停止运行

打开一个 PowerShell 窗口，进入项目目录后执行：

```powershell
.\.venv\Scripts\lelab.exe --stop
```

该命令会停止正在运行的 LeLab，并释放 `8000` 端口以及机械臂、摄像头等资源。

## 重新启动

先停止当前服务：

```powershell
.\.venv\Scripts\lelab.exe --stop
```

然后重新启动：

```powershell
.\.venv\Scripts\lelab.exe --no-open
```

重新打开或刷新浏览器页面：

```text
http://127.0.0.1:8000
```

## 常见问题

## Hugging Face 登录（在页面里直接登录）

1. 打开 LeLab 页面，看**右上角**：未登录时显示 `Log in`（HF 徽标）。
2. 点击后粘贴 Access Token（<https://huggingface.co/settings/tokens>，需要
   Read + Write），确定。
3. 成功后右上角显示用户名，顶部"未登录"横幅消失。

Token 保存在这台机器（Jetson 或 Windows）的 `~/.cache/huggingface/token`，
不会写进项目文件；训练/推理作业会自动把它带到训练机使用。

> 网络：本项目在部分网络环境下无法直连 huggingface.co。
> Windows 上先开 Mihomo/Clash（混合端口 7890，开 allow-lan），Jetson 已在
> `shared/config/jetson.env` 中配置 `HTTPS_PROXY=http://192.0.2.24:7890`；
> 训练机走 `https://hf-mirror.com`。改完代理后重启 LeLab 生效。

## 云端推理（策略跑在训练服务器上）

1. Jobs 列表里点某个 checkpoint 的 **Inference**；
2. `Compute target` 选 **Train server — trainer@192.0.2.10**；
3. 绑定相机 → **Start Inference**。

LeLab 会自动在训练机启动 PolicyServer、开 SSH 隧道，并在本机运行
`robot_client`；机械臂的安全限幅（`LELAB_MAX_RELATIVE_TARGET` 等）仍然只在
本机生效。停止时点 Stop 即可（会依次停 client / 隧道 / server）。

训练机会把 Hub 上的策略先下载到
`~/Desktop/lelab_server/models/policies/<repo>` 再加载。

### 提示 8000 端口已被占用

先执行停止命令，再重新启动：

```powershell
.\.venv\Scripts\lelab.exe --stop
.\.venv\Scripts\lelab.exe --no-open
```

### 页面无法打开

确认 PowerShell 中没有启动错误，然后检查：

```text
http://127.0.0.1:8000/health
```

正常情况下会返回服务器运行状态。

### 串口或摄像头无法连接

- 关闭其他可能占用摄像头的软件。
- 确认机械臂已经供电，USB 串口线连接正常。
- 停止并重新启动 LeLab，让程序重新检测设备。
- 同一串口不能同时被多个程序占用。

## 机械臂安全提醒

- 正式遥操作前必须完成 leader 和 follower 的正确端口配对与标定。
- 校准时缓慢、手动移动各关节，不要用力顶住机械硬限位。
- 首次遥操作时保持低速、小幅度，并确保可以随时断电。
- 机械臂运动范围内不要放置手、线缆或容易碰撞的物体。
